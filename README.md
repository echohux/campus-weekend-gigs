# 周末搭子 · Campus Weekend Gigs

连接大学生与校园周边商家的周末兼职撮合平台 MVP。

## 在线 Demo

**[点击打开周末搭子 Demo](https://echohux.github.io/campus-weekend-gigs/)**

无需本地安装，浏览器直接打开即可体验。首次登录后可选择：

- 学生端：核验学生身份、浏览兼职、提交报名
- 商家端：核验商家身份、发布周末兼职、管理报名

> 当前为前端 MVP 演示，演示数据保存在浏览器 `localStorage` 中，请勿填写真实敏感身份信息。

## 本地开发

```bash
npm install
npm run dev
```
